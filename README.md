Device Tree for Redmi 15C/Poco C85 (dew)
==========================================

The Redmi 15C/Poco C85 (codenamed _"dew"_) is a low-end smartphone from Xiaomi.
It was released in August 2025.

| Basic                   | Spec Sheet                                                                                                                     |
| -----------------------:|:------------------------------------------------------------------------------------------------------------------------------ |
| CPU                     | Octa-core (2x2.0 GHz Cortex-A75 & 6x1.8 GHz Cortex-A55)                                                 |
| Chipset                 | MediaTek MT6768 Helio G81-Ultra (12 nm)                                                                                       |
| GPU                     | Mali-G52 MC2                                                                                                                   |
| Memory                  | 4/6/8 GB RAM                                                                                                                     |
| Shipped Android Version | 15.0                                                                                                                           |
| Storage                 | 64/128/256 GB                                                                                                                    |
| Battery                 | Non-removable Li-Po 5160 mAh battery 18W                                                                                           |
| Display                 | IPS LCD 120Hz, 450 nits (typ), 600 nits (HBM)                               |
| Camera (Back)(Main)     | 50 MP, f/1.8, 28mm (wide), PDAF                                                                                 |
| Camera (Front)          | 8 MP                                                                                                                          |
